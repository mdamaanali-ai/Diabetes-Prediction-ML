## Diabetes Prediction ML

A Machine Learning project that predicts whether a person is likely to
have diabetes based on health-related parameters. The project includes
data preprocessing, exploratory data analysis, model training,
evaluation, and an interactive Streamlit web application.

## 🚀 Project Overview

This project uses Machine Learning to analyze diabetes-related patient
data and predict the diabetes outcome.

## Features

Upload a CSV dataset

Preview uploaded data

Dataset statistics and summary

Missing-value analysis

Duplicate-value analysis

Numerical data visualization

Correlation heatmap

Diabetes prediction using Logistic Regression

Model accuracy and ROC-AUC evaluation

Confusion matrix

Classification report

ROC curve

Feature importance

Interactive prediction for new patient data

## 📊 Machine Learning Model

The project uses Logistic Regression, a classification algorithm
suitable for predicting a binary outcome such as:

0 → No Diabetes

1 → Diabetes

The dataset is preprocessed before training. Missing or invalid values
are handled, numerical features are scaled, and the data is divided into
training and testing sets.

## 📈 Model Evaluation

## 💻 How to Run Locally

1. Clone the repository

git clone https://github.com/mdamaanali-ai/Diabetes-Prediction-ML.git
cd Diabetes-Prediction-ML

2. Install dependencies

pip install -r requirements.txt

3. Run the Streamlit application

streamlit run Diabetes_Prediction.py

The application will open in your browser.
